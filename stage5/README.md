## הרצה מהירה

```powershell
# משורש הפרויקט
docker compose up -d

cd stage5
npm install
npm run dev:server   # טרמינל 1 — :3001
npm run dev          # טרמינל 2 — :3000
```

פתחי: http://localhost:3000
