# הוראות כניסה והפעלה — מערכת ניהול נהגים

## הרצה מומלצת — Docker (הגשה)

**דרישה:** [Docker Desktop](https://www.docker.com/products/docker-desktop/) בלבד.

```powershell
# משורש drivers/
copy .env.example .env
docker compose up --build
```

פתחי: **http://localhost:3000**

פרטים מלאים: [DOCKER.md](../DOCKER.md)

---

## הרצה מקומית (לפיתוח)

### דרישות מקדימות

- Node.js **18 ומעלה** (`node -v`)
- Docker Desktop (PostgreSQL)
- קובץ `.env` בשורש הפרויקט (`drivers/.env`):

```env
DB_USER_SECRET=yael
DB_PASSWORD_SECRET=yael
DB_NAME_SECRET=try
DB_PORT=5433
PGADMIN_EMAIL=your@email.com
PGADMIN_PASSWORD=yourpassword
```

> `DB_PORT=5433` נדרש רק אם מותקן PostgreSQL מקומי על פורט 5432.

---

## הפעלת המערכת (מקומית)

### 1. הרמת בסיס הנתונים

```powershell
cd drivers
docker compose up -d db pgadmin
```

### 2. התקנת חבילות

```powershell
cd stage5
npm install
```

### 3. הרצת השרת (טרמינל 1)

```powershell
npm run dev:server
```

בדיקה: http://localhost:3001/api/health

### 4. הרצת הממשק (טרמינל 2)

```powershell
npm run dev
```

פתיחה: **http://localhost:3000**

---

## כניסה למערכת

### כניסת נהג

1. פתחי http://localhost:3000
2. הזיני מזהה קיים (למשל `1001`, `1131`)
3. לחצי **כניסת נהג**

### כניסת מנהל

לחצי **כניסת מנהל** במסך ההתחברות.

## פתרון בעיות

| בעיה | פתרון |
|------|--------|
| `role "yael" does not exist` | PostgreSQL מקומי תופס פורט 5432 — הוסיפי `DB_PORT=5433` ל-`.env` |
| `database: disconnected` | ודאי ש-Docker רץ |
| פורט 3001 תפוס | עצרי `dev:server` ישן (`Ctrl+C`) |
| `duplicate key driver_pkey` | מזהה נהג כבר קיים — בחרי ID אחר |
