# הוראות כניסה והפעלה — מערכת ניהול נהגים

## דרישות מקדימות

- Node.js **18 ומעלה** (`node -v`)
- Docker Desktop (PostgreSQL)
- קובץ `.env` בשורש הפרויקט (`drivers/.env`):

```env
DB_USER_SECRET=yael
DB_PASSWORD_SECRET=yael
DB_NAME_SECRET=try
PGADMIN_EMAIL=your@email.com
PGADMIN_PASSWORD=yourpassword
```

---

## הפעלת המערכת

### 1. הרמת בסיס הנתונים

משורש הפרויקט:

```powershell
cd drivers
docker compose up -d
```

- PostgreSQL: `localhost:5432`
- pgAdmin: http://localhost:8080

### 2. התקנת חבילות

```powershell
cd stage5
npm install
```

### 3. הרצת השרת (טרמינל 1)

```powershell
cd stage5
npm run dev:server
```

בדיקה: http://localhost:3001/api/health  
תשובה תקינה: `{"status":"ok","database":"connected"}`

### 4. הרצת הממשק (טרמינל 2)

```powershell
cd stage5
npm run dev
```

פתיחת האפליקציה: **http://localhost:3000**

## כניסה למערכת

### כניסת נהג

1. פתחי http://localhost:3000
2. בשדה **מזהה נהג (ID)** הזיני מזהה קיים מטבלת `driver` (למשל `1001`, `1131`)
3. לחצי **כניסת נהג**

**מה אפשר לעשות כנהג:**
- **רשימת הנסיעות שלך** — צפייה בכל הנסיעות המשויכות
- **לוח שנה** — נסיעות לפי חודש
- **סיכום נסיעות** — סטטיסטיקה לפי סטטוס וחודש
- **בקשת ביטול** — שליחת בקשה לביטול נסיעה מתוכננת

### כניסת מנהל

1. במסך ההתחברות לחצי **כניסת מנהל** (ללא הזנת מזהה)
2. נפתח ממשק ניהול עם 5 טאבים

## הפעלת ממשק המנהל

### טאב נהגים

| פעולה | איך |
|--------|-----|
| צפייה ברשימה | עמודות: שם, ID, טלפון, רישיון, **מספר נסיעות** |
| הוספת נהג | **הוספת נהג** → מלאי שם, מזהה, טלפון, סוג רישיון → **שמור נהג** |
| עריכת נהג | כפתור עיפרון → עדכון → **שמור נהג** |
| פרטי נהג + ניתוח אזור | כפתור עין → מודל עם **ניתוח אזור פעילות** ונסיעות משויכות |
| מחיקת נהג | כפתור מחיקה (רק לנהג **בלי** נסיעות) |

### טאב כלים

| פעולה | איך |
|--------|-----|
| צפייה ברשימה | מספר רישוי, יצרן, דגם, שנה, קיבולת, סוג |
| הוספת כלי | **הוספת כלי** → מלאי פרטים → **שמור כלי** (מזהה נוצר אוטומטית) |

### טאב מסלולים

| פעולה | איך |
|--------|-----|
| צפייה ברשימה | שם, יציאה→יעד, אזור, משך, מרחק, מספר תחנות |
| צפייה בתחנות | כפתור עין על מסלול |
| עדכון סטטיסטיקות | **עדכון סטטיסטיקות** — מריץ פרוצדורת `update_route_statistics` ומעדכן משך |
| יצירת מסלול | **מסלול חדש** → שם, אזור, תחנות, שעות הגעה → שמירה |

### טאב לוח נסיעות

| פעולה | איך |
|--------|-----|
| תצוגת רשימה / לוח שנה | מתג בראש העמוד |
| שיבוץ נסיעה | **שיבוץ נסיעה** → בחרי נהג, אוטובוס, מסלול, תאריך, שעה → **בצע שיבוץ** |
| צפייה בפרטי נסיעה | לחיצה על כרטיס נסיעה |

> בעת שיבוץ, טריגר `trg_validate_driver` בודק ב-DB שהנהג קיים. אם השיבוץ הצליח — מוצגת הודעה ירוקה והרשימה מתעדכנת.

### טאב בקשות ביטול

1. מוצגות נסיעות בסטטוס **ממתין לאישור**
2. **אשר ביטול** — הנסיעה עוברת ל«מבוטל»
3. **דחה בקשה** — הנסיעה חוזרת ל«מתוכנן» (הנהג מקבל הודעה)

## פתרון בעיות

| בעיה | פתרון |
|------|--------|
| `database: disconnected` | ודאי ש-Docker רץ וש-`DB_NAME_SECRET` ב-`.env` נכון |
| שגיאת Node / `tsx` | שדרגי ל-Node 18+ |
| פורט 3001 תפוס | `netstat -ano \| findstr :3001` → `taskkill /PID <מספר> /F` → הפעילי שוב את השרת |
| מזהה נהג לא נמצא | השתמשי ב-`driverid` קיים ב-DB (בדיקה ב-pgAdmin: `SELECT driverid, fullname FROM driver LIMIT 10`) |
| `Cannot GET /api/...` | השרת לא רץ — הפעילי `npm run dev:server` |
| אובייקטי שלב ד' חסרים | הפעילי מחדש את `npm run dev:server` (יוצר פונקציה, פרוצדורה וטריגר) |
